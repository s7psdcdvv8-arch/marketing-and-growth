# Adaptações das metodologias

Esta pasta registra como as skills externas são adaptadas para a Vilela Imóveis sem alterar os repositórios originais.

## Princípios

- **Originais intocados.** As skills de [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) e [advisorita/storytelling-frameworks](https://github.com/advisorita/storytelling-frameworks) são usadas como estão. Nada é copiado ou reescrito aqui.
- **Adaptação por camada.** Cada adaptação mantém a estrutura da skill original (mesmas seções, mesma ordem) e acrescenta só o que muda para o mercado imobiliário brasileiro.
- **Uma fonte de contexto.** Todas as skills leem `.agents/product-marketing.md`, que é o caminho padrão do método original.
